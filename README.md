# 🚀 Codeforces Solutions - Brute Force to Optimal

Welcome to my **Codeforces Problem-Solving Repository**!

This repository documents my competitive programming journey, where I solve Codeforces problems one by one and focus on understanding the logic, improving problem-solving skills, and optimizing solutions.

Instead of just sharing the final code, I aim to explore different approaches - from **Brute Force to Optimal Solutions** - and understand why one approach performs better than another.

## 🧠 My Problem-Solving Approach

For each problem, I try to follow these steps:

1. Understand the problem statement and constraints.
2. Identify a straightforward approach.
3. Implement the Brute Force solution, when applicable.
4. Analyze its time and space complexity.
5. Look for a more efficient approach.
6. Implement and analyze the Optimal Solution.
7. Test the code against sample cases and edge cases.
8. Document the key idea and lessons learned.

**Note:** Not every problem requires two different solutions. If the straightforward approach is already optimal, I will document that accordingly.
